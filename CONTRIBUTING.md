# Contributing

## Rules

- English only for skill content.
- Do not invent research citations.
- Keep critique **constructive** (improve outcomes, not insult users).
- Preserve mode system and “just execute” escape hatch.
- When bumping version: update SKILL frontmatter, README badge, and CHANGELOG together.

## Process

1. Open an issue for gaps or failures (e.g. still too agreeable on X).
2. PR with rationale.
3. Do not expand into general therapy, legal practice, or multi-model infrastructure code unless scoped as optional docs.
