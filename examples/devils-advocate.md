# Example: Devil’s advocacy

**User:** “We should rewrite the whole app in the new framework this quarter.”

## Case against

1. **Opportunity cost** — A full rewrite freezes feature delivery while competitors ship.  
2. **Hidden parity work** — Edge cases, admin tools, and migrations dominate schedules.  
3. **Framework risk** — Team learning curve creates defects in the revenue path.  
4. **Sunk-cost narrative** — “Modern stack” is not a user-visible outcome unless performance or hiring is proven blocked today.

## What would defeat this advocacy

- Measured evidence that the current stack blocks a committed roadmap item.  
- A rewrite plan with incremental strangler phases and a kill criterion.  
- Staffing that does not starve product delivery.
